# Homebrew Tap for Lantern

Official Homebrew tap for [Lantern](https://github.com/misterekkk/lantern) — local-first multimodal semantic search for macOS.

## Installation

Install Lantern directly:

```bash
brew install --cask misterekkk/tap/lantern
```

Or add the tap first and then install:

```bash
brew tap misterekkk/tap
brew install --cask lantern
```

## Updating

To update Lantern to the latest release:

```bash
brew upgrade --cask lantern
```

## Uninstallation

To remove Lantern along with its application state:

```bash
brew uninstall --cask --zap lantern
```
